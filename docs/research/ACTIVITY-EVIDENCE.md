# 활동 초안과 근거의 범위

작성·재검토일: 2026-10-12 · 상태: 출처별 서지·초록·공개 전문 검토, 일부 전문 미확인

## 조사 상태와 403 진단

이전에는 HTTPS 프록시가 `Tunnel connection failed: 403 Forbidden`을 반환했다. 이는 대상 사이트와 TLS 연결을 맺기 전 외부 연결이 거부됐다는 뜻이며, 앱 코드 오류나 사용자의 휴대폰 오류가 아니다. 당시 실행 환경의 외부 접근 제한과 일치했지만 내부 원인을 단정할 수는 없다.

이번 재확인에서는 WHO 공식 안내, Crossref, Europe PMC, PMC 요청이 HTTP 200으로 응답했다. 저장된 설정 초안에는 관련 허용 도메인이 이미 포함돼 있다. 설정 적용 여부 자체를 접속 성공만으로 단정하지 않는다. 지금 핵심 기관/API 자료를 읽기 위한 사용자 조치는 필요 없다. 개별 사이트 오류는 별도로 남아 있다: James Clear 소개 페이지 HTTP 403, 일부 Europe PMC 전문 API HTTP 500, Crossref 일부 요청 HTTP 429. 마지막 오류는 요청 제한이며 프록시 차단과 다르다. PMC HTML HTTP 200만으로 논문 본문을 읽었다고 판정하지 않았다.

확인 범위:

| 자료 | 실제 확인한 범위 | 남은 한계 |
| --- | --- | --- |
| WHO / Bull 2020 | WHO 공식 안내 접근 및 Europe PMC 서지·초록·공개 전문(권고·논의·결론) | 개인별 운동 처방이나 앱의 걷기 강도 검증이 아님 |
| Dunlosky 2013 | Crossref·Europe PMC 서지와 초록 | 논문 전체의 방법·개별 연구를 재평가하지 않음 |
| Gollwitzer & Sheeran 2006 | Crossref 제목·DOI·발행연도 | 초록·전문 미확인. 효과 크기나 상세 결과를 직접 검증했다고 주장하지 않음 |
| Harkin 2016 | Europe PMC 서지·초록 | 전문 및 개별 실험 미확인 |
| Goyal 2014 | Europe PMC 저널 논문 서지·초록 | 전문 API 500. 같은 DOI 검색에 함께 나온 AHRQ 보고서와 구분해 저널의 47개 시험 결과를 사용 |
| Watson 2015 | 원 DOI 및 동시 발표 DOI 10.5664/jcsm.4758의 서지·초록 | 초록은 권고 생성 방법만 기술함. 7시간 권고 문구가 담긴 본문은 직접 확인하지 못함 |
| Holt-Lunstad 2010 | Europe PMC 서지·초록·공개 전문(논의·한계) | 관찰 자료의 관계를 특정 연락 루틴의 인과 효과로 환산하지 않음 |
| Atomic Habits | 공식 소개 페이지 재요청은 403 | 책 본문 미확인. 실용서 참고 아이디어이며 실험 근거로 사용하지 않음 |

DOI 조회는 `https://api.crossref.org/works/{DOI}`, 초록은 `https://www.ebi.ac.uk/europepmc/webservices/rest/search`의 DOI 검색과 `resultType=core`, 공개 전문은 같은 API의 `PMC7719906/fullTextXML`, `PMC2910600/fullTextXML`로 확인했다. 전체 최신 문헌을 체계적으로 검색한 결과는 아니다.

## 재검토 결과와 앱 반영

- 운동: WHO 성인 권고는 중강도 150–300분/주 또는 고강도 75–150분/주, 근력 운동 2일 이상이다. 걷기 10분/주70분은 작게 시작하는 예시이며 편한 걷기를 자동으로 중강도 권고 달성으로 계산하지 않는다. 움직임은 짧아도 가치가 있고 일률적인 10분 최소 단위는 필요하지 않다.
- 학습: 회상 시험과 간격 학습은 초록에서 높은 유용성으로 평가한다. 독서량만 늘리기보다 책을 덮고 떠올린 뒤 확인하는 기록을 우선한다. 앱의 10분은 검증된 학습 용량이 아니다.
- 점검: Harkin 초록은 무작위 배정 연구 138개, 19,951명에서 목표 달성 효과 d=0.40(95% CI 0.32–0.48)을 보고한다. 앱의 효과 크기가 아니며 주 1회가 최적이라는 근거도 아니다. 기록과 실제 결과를 비교하는 주간 회고를 선택 활동으로 유지한다.
- 명상: Goyal 저널 논문의 47개 시험, 3,515명에서 불안·우울·통증에 중간 수준의 근거를 보고한다. 주의력·수면·체중 등에 충분한 개선 근거가 없고 비교한 적극적 치료보다 우월하다는 증거도 없다. 앱의 3분 휴식과 같은 개입이 아니므로 선택 활동으로 둔다.
- 관계: 148개 연구, 308,849명에서 관계와 생존의 연관성을 보고했지만 인과 판단·교란 통제·지역 대표성에 한계가 있다. ‘주 2회 안부’로 수명이나 건강 향상을 약속하지 않는다.
- 실행 계획과 수면 준비: 실천 아이디어로 유지하되 전문 미확인 범위를 표시한다. 계획한 것과 실행한 것, 준비한 것과 실제 잠을 잔 결과를 구분한다.

기본 세 활동은 걷기·회상 학습·다음 행동 계획으로 유지한다. 다음 행동 계획 설명을 ‘상황이 되면 행동한다’는 조건-행동 문장으로 구체화했다. 화면의 일괄 ‘접근 차단’ 문구를 제거하고 출처별 확인 범위를 추가했다. 기존 사용자 기록·목표·XP 배점은 변경하지 않았다.

## 기본 구성 원칙

새 사용자는 걷기·회상 학습·다음 행동 계획의 세 활동으로 시작하도록 제안한다. 수면·마음·관계·점검은 필요할 때 선택한다. 모두 선택 사항이며 사용자는 직접 항목·분류·목표를 계속 추가할 수 있다. 시간/주간 횟수는 시작 예시이고 연구에서 도출한 최적 용량이 아니다. 기존 사용자의 항목과 기록을 자동으로 바꾸지 않는다.

## 경험치 규칙

‘기록 루틴 v1’의 설계값이다. 연구 효과 점수나 건강·지능·근력 점수가 아니다.

- 항목별 하루 첫 유효 기록 +10 XP.
- 측정형: 유효한 숫자(0도 가능). 수량·시간·최고 기록: 0 초과. 체크형: 완료.
- 같은 날짜·항목의 여러 기록은 한 번만 보상. 일일 합계 최대 50 XP.
- 100 XP마다 레벨 증가: 레벨 = 1 + floor(총 XP / 100).
- 숫자를 크게 입력하거나 목표를 달성했다고 추가 XP를 주지 않음.
- 수정·삭제·체크 취소는 재계산. 쉬는 날 자체로 차감하지 않음.
- 과거 기록과 보관 항목도 같은 규칙. 사진·설정 변경은 XP 없음.
- 오늘 내역에 소계, 일일 상한 차감, 최종 XP를 표시함.

10/50/100은 이해하기 쉬운 게임 보상 단위로 선택한 수치다. 연구에서 검증된 배점이 아니므로 실제 성장은 원본 기록·목표·결과 변화에서 판단한다.

## 활동 균형

축은 기록 항목이 있는 분류로 만든다. 기존 기본 분류가 4개였기 때문에 마름모였다. 네 축이 특별히 과학적인 인간 능력 모형이어서 선택된 것이 아니다. 세 분류는 삼각형, 여섯 분류는 육각형이다. 한 번에 3~8개 분류를 선택해 비교하고 나머지는 상세 수치로 볼 수 있다. 분류·항목 자체는 계속 추가할 수 있다.

축 값은 ‘선택 기간 중 그 분류에 유효 활동 기록이 있는 날짜 수 / 기간 일수’다. 측정은 유효한 입력, 활동은 0 초과를 셈. 운동·수면·관계를 같은 단위로 더하거나 다각형 면적을 전체 건강 점수로 쓰지 않는다. 빈도만 비교하므로 활동의 질·강도·목표에 맞는 휴식은 이 차트로 판정할 수 없다.

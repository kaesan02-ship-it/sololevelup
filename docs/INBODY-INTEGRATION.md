# 인바디 연동 검토 — 2026-10-12

## 현재 결론

사용 중인 인바디 앱·프로그램 이름, 기기 모델과 계정의 내보내기 기능이 확인되지 않아 자동 연동 가능 여부를 확정할 수 없다. 공식 홈페이지(https://www.inbody.com/ 및 https://inbodyusa.com/)에 접근했지만 환경 프록시가 `Tunnel connection failed: 403 Forbidden`으로 차단했다. 따라서 이번 작업에서 공식 API 문서·계약 조건을 읽고 지원을 확인했다고 주장하지 않는다. 필요한 도메인은 환경 설정 초안에 추가했으며 저장·게시 후 접근을 재확인할 수 있다.

## 가능한 연결 방식과 전제

| 방식 | 필요한 조건 | 현재 앱에 적용할 때 |
| --- | --- | --- |
| 공식 API | 해당 제품/지역/개인 또는 기관 계정에서 API 제공, 접근 권한, 사용자 동의, 인증 문서 | 먼저 제조사 확인 필요. 비밀 API 키가 필요하다면 현재 정적 웹사이트 외에 인증·키를 보관할 서버가 필요함 |
| CSV/Excel 내보내기 | 사용 중인 프로그램이 실제로 파일 내보내기를 지원해야 함 | 샘플의 측정일·체중·골격근량·체지방률과 단위 확인 후 미리보기·중복 확인을 거쳐 가져오기 구현 가능. 현재 자동 가져오기는 없음 |
| 결과지/PDF/사진 | 사용자가 결과물을 제공할 수 있어야 함 | 문자 인식 후 사용자 확인 절차를 거쳐 저장하는 기능 구현 가능. 소수점·단위·측정일 오류를 확인 없이 자동 저장하면 안 됨. 현재 OCR은 없음 |
| 직접 기록 | 측정 결과를 확인할 수 있으면 됨 | 현재 체중·골격근량 기본 항목과 직접 추가한 체지방률(수치 측정, %)로 기록 가능. 날짜별 보기에서 측정일을 선택해 기록 |

## 우선 권장안

현재는 날짜별 수동 기록으로 시작하고, 프로그램에서 파일을 내보낼 수 있다면 그 형식을 확인해 가져오기를 추가한다. 공식 API는 제조사 제공 조건을 확인한 뒤 결정한다. 개인 앱의 비밀번호를 수집하거나 로그인 화면을 자동으로 긁어오는 방식은 채택하지 않는다.

추가 확인에 필요한 정보는 사용하는 앱/프로그램의 정확한 이름, 기기 모델(알 수 있는 경우), 파일 내보내기 메뉴의 유무다. 결과지 사진 자체가 API 권한을 의미하지는 않는다. 현재 프로필 사진 업로드는 사진을 표시·저장하는 기능이며 체성분을 추출하지 않는다.

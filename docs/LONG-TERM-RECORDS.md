# 쉬운 용어와 오래 쌓는 기록 · 2026-10-13

## 변경 내용
- 회상 학습 → 배운 내용 떠올리기: 책·노트를 덮고 배운 내용을 생각해본 뒤 확인하는 연습이다.
- 마음챙김 휴식 → 호흡에 집중하며 쉬기, 다음 행동 계획 → 다음에 할 일 정하기.
- 스냅샷 → 변화 요약, 스탯 → 능력치, 회고 → 일기. 추천 활동의 연구 설명도 읽기 쉬운 표현으로 정리했다.
- 기존 추천 활동은 practiceId와 원래 이름이 모두 일치하는 경우에만 이름을 바꾼다. 사용자 지정 이름·ID·날짜·수치는 유지한다.
- 기존 화이트/라벤더/민트 색을 유지하고 카드·입력창·버튼 테두리와 제목 굵기, 주요 아이콘 선을 강화했다.

## 저장 기간과 달력
84일은 이전 화면의 표시 범위였다. 저장/백업/동기화 코드에 날짜가 오래됐다는 이유로 기록을 삭제하는 기능은 없다.

달력을 실제 월 단위로 바꾸고 이전/다음 달, 월·연도 직접 선택, 기록 있는 연도 선택, 첫 기록 이동, 연간 월별 기록일 수를 제공한다. 일기만 작성한 날도 달력과 연간 요약에 포함한다. 날짜별 전체 기록을 조회하며 조회 범위와 저장 범위를 혼동하지 않도록 설명한다. 날짜별 개수를 미리 계산해 각 칸마다 전체 기록을 다시 훑지 않는다.

‘무제한 저장’을 약속하는 것은 아니다. 브라우저 저장 공간, 사용자에 의한 삭제/브라우저 데이터 정리, 현재 클라우드 문서당 전송 크기 제한(10MB)이 있다. 정기 JSON 백업을 권장한다. 수년간 매우 많은 사진/기록이 쌓이면 서버 분할 저장이 후속 과제다.

## 현재 능력과 역대 최고
최고 기록 항목은 기존의 역대 최고를 보존하면서 홈·능력치·상세 화면에 가장 최근 수치와 측정 날짜를 추가했다. 상세 화면은 직전 기록과의 차이 및 최고 기록에 미치지 못하는 상태도 표시한다. 예: 예전 30회, 최근 20회라면 역대 최고 30회 / 최근 20회 / 직전 대비 -10회.

작을수록 좋은 항목(예: 달리기 소요 시간)도 비교 방향을 반영한다. 기록이 없는 날의 체력 감소를 추정하지 않으며 한 번의 낮은 기록을 장기적인 퇴행으로 진단하지 않는다. XP는 기록 습관을 나타내므로 현재 능력과 분리하여 유지한다.

# SVG 디자인 개선 · 2026-10-13

밝은 홈 카드에 곡선 궤도와 별빛을 직접 그린 SVG로 추가하고, 사진 테두리를 정리했다. 나의 스탯에는 오늘 XP / 하루 최대 XP에 비례하는 원형 게이지를 넣었다. 모바일에서는 게이지와 숫자를 나란히 배치한다.

SVG는 외부 이미지 요청 없이 렌더링하며 장식은 aria-hidden, focusable=false와 pointer-events:none을 적용한다. 텍스트로도 경험치를 그대로 제공한다. 애니메이션은 없다.

검증: 프로덕션 빌드, TypeScript, 기존 브라우저 테스트 19개 통과. 모바일 360/393/412px 및 가로 900px 화면, 사진 업로드, 기록 수정, 날짜별 조회, 백업, 오프라인 동작을 포함한다. Android 기기 실측이 아닌 Chromium 모바일 에뮬레이션이다.

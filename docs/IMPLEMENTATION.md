# 현재 구현 현황

2026-10-12 · 화이트톤·사진 프로필·동기화 확장

## 구현

화이트톤 모바일/PC 화면, 기본 세트와 자유 항목·분류, 다섯 기록 방식, 기록 CRUD, 고정·정렬·보관, 성장 비교/그래프, 목표, XP·레벨·업적, JSON 백업·복원, CSV 내보내기, 본인 사진 등록, 홈 화면 설치, 오프라인 재실행과 기록 저장.

이전 그림 캐릭터와 꾸미기는 제거했다. 이전 백업/브라우저 데이터의 기록을 보존하고 과거 외형 설정은 사용하지 않는다. 사진 기반 AI 캐릭터 생성은 원본 사진과 별도 제작 과정이 필요하며 현재 앱의 자동 생성 기능은 아니다.

로그인·기기 간 동기화 코드와 Supabase SQL을 구현했다. 사진도 동기화하고, 로컬 변경을 먼저 저장하며, 저장 중 추가된 기록은 대기 상태를 유지한다. 서버 버전이 다른 경우 자동 덮어쓰지 않고 어느 기기 기록을 보관할지 선택한다. 첫 연결도 기록을 자동 합치지 않고 선택하도록 구성했다.

## 검증과 남은 단계

핵심 계산·사진·호환·충돌 규칙 테스트, 브라우저 기능 테스트, 모의 두 기기 동기화 테스트와 빌드를 실행한다. 모의 테스트는 실제 Supabase Auth·DB·RLS 검증과 구분한다.

실제 Supabase 프로젝트가 아직 없어 연결 후 실제 로그인·기기 동기화·계정 격리를 검증해야 한다. 필요한 변수와 네트워크 목적지는 환경 설정 초안에 저장했다. 프로젝트 생성·SQL 적용·공개 연결 정보 설정은 SUPABASE-SETUP.md에 안내한다. 공개 HTTPS 배포는 완료했으며 실제 휴대폰 OS에서의 검증은 별도로 필요하다.

현재 검증 결과: 계산·사진·호환·동기화 규칙 테스트 21개, 실제 브라우저 로컬 기능 테스트 19개, 모의 API를 이용한 두 기기 동기화 테스트 1개 모두 통과했다. 타입 검사와 배포용 빌드도 통과했다. 실제 Supabase 프로젝트의 가입 메일·Auth·SQL/RLS 는 아직 검증하지 못했으며 연결 정보가 필요하다. 공개 HTTPS 배포와 해당 주소의 모바일 브라우저 모의 검증은 완료했다.

스냅샷·스탯 확장: 고정 항목은 8개까지 선택하며 고정/최근/전체 모드와 분류 필터, 90일 비교를 지원한다. 나의 스탯 페이지에 누적/오늘 XP, 활동일과 현재/최장 연속 기록, 분류별 활동 비율 차트, 목표, 84일 캘린더, 날짜별 원본 기록과 전체 상세 지표를 추가했다. 기록과 성장 상세 화면으로 연결되며 모바일 넘침과 체크 취소 상태 표시를 검증했다. 중립 방향 측정 목표의 달성 판정도 보완했다. 상세 점검은 PAGE-AUDIT.md를 참고한다.

안드로이드·폰트·활동 초안: Pretendard Variable 원본을 앱에 포함하고 라이선스를 보존했다. Android Chrome 모의 환경(360/393/412px 세로, 900px 가로, DPR3 터치)에서 조작·이미지·차트·폰트·좁아진 입력 화면을 확인했다. 큰 사진 최적화와 손상된 사진 대체, 오프라인 폰트 로딩도 검증했다. XP 규칙과 당일 계산 내역을 공개하고 차트 축을 선택할 수 있게 했다. 추천 루틴은 선택 가능한 문헌 기반 구성이다. 2026-10-12 네트워크 재확인 후 WHO·사회적 관계의 공개 전문과 학습·진행 점검·명상의 초록을 검토했다. 실행 의도는 서지만 확인했으며 수면 권고 본문과 책 본문은 미확인이다. 출처별 확인 범위를 표시한다. 상세 내용은 ANDROID-UI.md와 research/ACTIVITY-EVIDENCE.md에 기록했다.

## 스냅샷 확장

기존 4개 고정에서 8개 고정으로 변경했다. 측정·최고 기록·누적·시간·체크는 모두 사용자가 추가한 항목도 지원한다. 최근 기록 모드는 기록이 있는 항목을 최신 날짜순으로 보여주고, 전체 항목 모드는 모든 활성 항목을 보여준다. 8개를 넘는 전체/최근 목록은 ‘더 보기’로 펼친다. 고정 선택과 항목 순서는 저장·백업·동기화 데이터에 유지된다. 분류 필터와 표시 모드는 화면 보기 설정이며 영구 저장하지 않는다.

분류 예시를 추가하더라도 값이나 기록은 자동 생성하지 않는다. 독서, 공부, 저축, 명상, 악기 연습 등 사용자 항목을 그대로 사용할 수 있다.

## 수치의 의미

스탯 차트는 선택한 기간에 분류별로 기록한 고유 날짜 수 / 기간 일수다. 서로 다른 단위를 임의로 더하거나 실제 근력·지능·건강 점수로 환산하지 않는다. 측정은 0도 유효한 기록, 활동은 0보다 큰 값만 활동일에 포함한다. 과거 보관 항목은 누적 경험치와 활동 역사에 남는다.

현재 연속 기록은 오늘 입력 전이라도 어제까지 이어졌으면 유지한다. 이틀 이상 비면 0이다. 캘린더는 원본 기록 수를 표시하며, 오늘의 XP는 기존 하루 50 상한을 따른다.

## 점검에서 수정한 내용

방향을 ‘기록만’으로 둔 측정 목표는 첫 측정값과 목표값의 관계로 달성 방향을 계산한다. 예를 들어 시작 75kg→목표 70kg에서 현재 74kg을 달성으로 취급하지 않는다. 진행률은 20%, 남은 값은 4kg이다. 목표와 시작이 같으면 현재값이 목표와 같을 때만 달성이다. 명시적 증가/감소 방향이 있으면 그 방향을 따른다.

페이지 전환과 지표 상세 이동 시 화면을 위로 되돌리고, 분류 스탯 클릭은 전체 상세 지표의 해당 분류로 연결했다. 빈 데이터는 기록 대기/비교 불가로 표시한다.

## 검증 범위

계산·호환·스탯 규칙 테스트와 브라우저 테스트로 기록 CRUD, 사진·백업, 오프라인 재실행, 스냅샷 편집/필터/보존, 상세 스탯에서 기록/분석 이동, 모바일 가로 넘침, 정렬·보관 해제·분류 CRUD·CSV를 점검한다. 새 화면 예시는 preview-stats.png와 preview-stats-mobile.png에 저장한다.

Supabase 로그인·기기 동기화는 모의 API 검증 이력이 있으나 실제 프로젝트 연결이 없어 실제 계정·RLS·휴대폰 간 동기화 검증은 대기 중이다. 이 부분을 페이지별 로컬 기능 검증과 구분한다.

최종 결과: 계산·호환·스탯 규칙 테스트 18개, 브라우저 시나리오 10개, 타입 검사, 배포용 빌드 모두 통과했다. 초기 모바일 캘린더의 가로 넘침은 수정 후 재검증했다. 실제 Supabase 연결 검증은 여전히 별도 대기 단계다.

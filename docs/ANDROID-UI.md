# 안드로이드 UI와 반응형 점검

검증 대상은 실제 기기가 아닌 Android Chrome 모의 환경이다. Pixel 7 사용자 에이전트, 터치 입력, DPR 3, 한국어/서울 시간대를 사용한다. 360×800, 393×851, 412×915 세로와 900×412 가로 화면을 확인한다. 실제 안드로이드 OS 키보드·사진 선택기·삼성 인터넷·앱 내 WebView를 직접 테스트한 것은 아니다.

## 개선

- Pretendard Variable 원본 폰트를 앱에 포함(next/font/local). 라이선스는 app/fonts/OFL.txt. 외부 폰트 요청 없이 동작하며 생성된 정적 폰트는 오프라인 캐시에 포함한다.
- 작은 글씨를 키우고 한글 자간과 숫자 간격을 정리한다. 모바일 입력은 16px, 주요 터치 영역은 44px 이상으로 맞춘다.
- 화면 하단 안전 영역과 동적 화면 높이(dvh)를 적용하고 팝업 자체에서 스크롤한다. 터치 기기의 가로 화면에서도 하단 메뉴를 유지한다.
- 활동 차트는 화면에 맞게 크기를 조절하고 긴 축 이름은 줄여 표시한다. 전체 이름과 수치는 상세 목록과 접근성 설명에서 확인할 수 있다.
- 사진은 SVG 아이콘으로 대체 가능한 기본 프로필을 사용하며, 잘못된 저장 사진이 디코딩되지 않으면 브라우저의 깨진 그림 표시 대신 기본 프로필을 보여준다.
- JPG·PNG·WebP 최대 12MB를 선택할 수 있다. 큰 이미지는 원본 비율을 유지해 긴 변 1024px, 저장용 2MB 이하로 최적화한다. 기기의 원본 파일을 변경하지 않는다. 원본 해상도가 낮거나 초점이 맞지 않은 사진을 선명하게 복원하는 기능은 아니다.

## 모의 환경에서 확인하는 동작

폰트 실제 로딩, 가로 넘침, 하단 메뉴, 사진 표시/자연 크기, 숫자 입력/저장, 활동 차트 표시, 축 선택, 짧아진 화면에서 입력 팝업 저장, 큰 사진 최적화, 손상된 사진의 기본 표시, 추천 루틴 추가, XP 계산 내역, 4개 이상의 활동 분류 표시. 기존 오프라인 재실행 테스트에서 폰트 로딩도 확인한다.

실제 스마트폰 검증은 HTTPS 배포 후 Chrome에서 홈 화면 설치, 사진 선택/카메라, 키보드, 회전, 오프라인 재실행을 확인해야 한다. 기기 간 실제 동기화는 Supabase 프로젝트 연결 후 별도로 검증한다.

검증 결과: Android Chrome 모의 화면 4개와 추천/축/XP 시나리오, 큰 사진·손상 사진 시나리오를 포함한 브라우저 테스트 16개 모두 통과했다. 계산·호환·루틴 테스트 20개와 모의 두 기기 동기화 1개, 타입 검사·빌드도 통과했다. Android 네이티브 카메라·키보드나 실제 휴대폰에서의 실행을 확인했다고 주장하지 않는다.
